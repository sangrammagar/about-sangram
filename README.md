# Sangram Magar — AI & ML Portfolio

A responsive portfolio website focused on two recent live projects:
1. Smart Roster Management System
2. Loan Approval Prediction

It also highlights professional experience, education, technical skills, and additional AI projects.

## Run locally
Open `index.html` directly in your browser, or use a local server:

```bash
python -m http.server 8000
```

Then open http://localhost:8000

## Deploy on GitHub Pages
1. Create a repository named `sangrammagar.github.io` (or any repository for Pages).
2. Upload `index.html`, `styles.css`, `script.js`, and this README.
3. In repository Settings → Pages, select Deploy from a branch → `main` → `/root`.
4. Save and wait for deployment.
